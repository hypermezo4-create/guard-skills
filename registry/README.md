# skills.sh Registry Snapshot

This directory is generated by `npm run sync`.

Generated files:

- `skills.json` — normalized skills.sh catalog entries.
- `sources.json` — aggregate source repositories/providers and install counts.
- `summary.json` — snapshot metadata and totals.

The catalog is metadata, not a trust list. Third-party skill contents are not automatically executed, re-authored, or claimed by this repository.

The official skills.sh API requires an authenticated Vercel OIDC bearer token. The sync script accepts `VERCEL_OIDC_TOKEN` or `SKILLS_SH_TOKEN` from the environment and never writes the token to disk.
